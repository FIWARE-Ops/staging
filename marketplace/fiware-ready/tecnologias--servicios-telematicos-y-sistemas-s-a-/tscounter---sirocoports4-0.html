FIWARE-Ready: Tecnologías, Servicios Telemáticos y Sistemas S.A. - TScounTer - SirocoPORTS4.0 (Data Analytics,Data Spaces,Internet of Things,Mobility and Location,Open Data)

TScounTer is a people‑counting IoT device that detects nearby WiFi and Bluetooth signals and sends aggregated telemetry via LTE. It integrates with FIWARE through a custom IoT agent and forms part of the SirocoPORTS4.0 seaport digitalization and monitoring solution.

TScounTer is a people‑counting IoT device that detects nearby WiFi and Bluetooth signals, aggregates the number of unique devices, and transmits telemetry via LTE. It integrates into the FIWARE ecosystem through a custom IoT agent developed within the SirocoPORTS4.0 project, which provides a standardized, scalable solution for seaport monitoring. Its main benefits are:

  • Provides real‑time monitoring of device presence for port‑area analytics, supporting digitalization initiatives.
  • Ensures interoperability through FIWARE Smart Data Models and a uniform NGSI API.
  • Reduces configuration effort by using a simple payload format and centralized middleware logic.
  • Enhances maintainability and scalability by decoupling device communication from FIWARE‑specific logic.
  • Supports automatic entity creation and updating in FIWARE for consistent data lifecycle management.

Seaport digitalization requires consistent, real‑time awareness of activity across complex operational environments. In SirocoPORTS4.0, one of the main challenges is integrating heterogeneous edge devices, each using different communication protocols and data formats, into a unified FIWARE‑based context management framework. Devices such as TScounTer generate valuable telemetry, but without a standardized ingestion and transformation layer, their data cannot be reliably harmonized or exploited. To address this, the project employs a middleware architecture in which device measurements are collected, normalized, and forwarded through dynamically generated FIWARE endpoints, ensuring interoperability, scalability, and alignment with Smart Data Models. This approach enables ports to consolidate diverse sensor inputs into a coherent, secure, and extensible digital ecosystem.

TScounTer has been developed and validated within the SirocoPORTS4.0 innovation project, where it operates as part of the port‑digitization architecture that integrates heterogeneous IoT devices through a FIWARE‑based middleware. The solution has been developed and tested in real operational conditions thanks to the collaboration of multiple Spanish port authorities participating in the project’s validation activities. These Port Authorities have provided the the real‑world requirements, in which TScounTer telemetry is ingested, transformed, and forwarded to the Orion Context Broker using the SirocoPORTS4.0 middleware and rule‑chain mechanisms
